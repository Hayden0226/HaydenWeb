# 茶百戏图片选择器

一个基于 JavaScript 的茶百戏图案选择工具：从滚动画廊中挑选图案，实时预览，并借助 html2canvas 把选中的图案合成导出为图片。

## Features

- 滚动式图片画廊，左右按钮快速切换
- 启动弹窗与缩略图预览
- 图案合成与图片导出（html2canvas）
